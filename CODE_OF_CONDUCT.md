# Code of Conduct

We are committed to fostering an open, welcoming, and respectful community for everyone contributing to **Mini Ho Chi Minh 3D**.

## Our Standards

- Be respectful, constructive, and empathetic in issues, discussions, and code reviews.
- Welcome newcomers and help each other learn geospatial, WebGL, and Three.js concepts.
- Focus feedback on ideas and code rather than individuals.
- Harassment, discrimination, or disrespectful behavior will not be tolerated.

If you encounter unacceptable behavior, please report it to the repository maintainers via GitHub Issues or direct contact.
